## API, permissions, notes

- **API:** `roomSetup.saveRoomOrder(roomIds)` = `PUT /rooms/order` (section "Room order" in api-contract.md). Guard `assertRoomOrder` in `src/api/validation.ts`.
- **Permissions:** none new; the menu, reorder and Save Order follow the page's existing access (a user without access never reaches the page).
- **Notes:** pure rules in `src/app/roomOrder.ts` (move, apply, Schedule ordering) and `src/app/setupMoreMenu.ts` (labels, who gets the menu). Superseded: the "Rooms list: No Edit Room Order" line in figma-deviations.md (ticket 7.3).
