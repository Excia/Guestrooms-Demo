## API, permissions, notes

- **API:** `POST /reservations/{id}/cancel`, `POST /reservations/{id}/undo-check-in`, and `ReservationDetail.lastAuditedDate` (see the "Reservation menus (ticket 2.5)" section of `api-contract.md`).
- **Permissions:** `reservation.edit` (existing). `reservationMenu()` requires `canEdit` (no default: a missing value cannot open the menu).
- **Not seeded:** no mock reservation was added that is checked in and arrived today. To see Undo Check In live in dev, check a not-yet-checked-in reservation in from the Reservation List (arrival today, e.g. GR-50310); the mock audit date is yesterday.
- **Notes:** the dev server could not be driven in the Browser pane in this session (timeouts), so the UI was checked by component tests only, not against Figma in a real browser.
