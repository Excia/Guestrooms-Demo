## API, permissions, notes

- **API:** none changed; `endMarker` is documented as unused (api-contract.md).
- **Grid update:** ticking a checkbox in the panel calls `onEarlyLateSaved` in `src/pages/Schedule.tsx`, which patches the flags on every block of the reservation at once (it reloads for a stay that changed room). Test: `src/pages/Schedule.panel.test.tsx`, "Late Check Out on a not yet checked in reservation draws the right tab at once".
- **Closure fill (Q-EM-1):** legacy `ReservationScheduleViewRoomClosureBox.vue` uses a grey 45 degree striped gradient with fixed hex colors; ours is a flat grey token, so it does not match. Left unchanged (needs a token).
