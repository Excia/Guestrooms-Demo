# Glossary

Domain and project terms as used in the tickets, PRs and code. Where a source does not define a term the
entry says **Unknown**. Back to the [index](README.md).

## Reservation and stay

| Term                                | Meaning                                                                                                                                                                                                                                                                                                     |
| ----------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Reservation                         | A booking of one or more rooms for dates; has a confirmation number ("Res #", e.g. GR-48213)                                                                                                                                                                                                                |
| Reservation room                    | One room of a reservation. The schedule block `id` is the reservation-room id; blocks sharing a `reservationId` belong together                                                                                                                                                                             |
| Multi-room reservation              | A reservation with more than one room (`roomCount` above 1). Its status in lists is the "lowest common denominator" of its rooms; a partly checked-in one shows "Checked In"                                                                                                                                |
| Stay / night                        | A stay occupies the nights `[startDate, endDate)`; the departure day is not occupied                                                                                                                                                                                                                        |
| Same-day turnover                   | A departure on the day another stay arrives in the same room; not an overlap                                                                                                                                                                                                                                |
| NYCI                                | Not Yet Checked In: a reservation (or room) whose check in has not happened. In the schedule, status `nyci` means arrival day reached and not checked in; `confirmed` means arrival still ahead                                                                                                             |
| Due out                             | A checked-in block whose end date is today (departing)                                                                                                                                                                                                                                                      |
| Early check-in marker               | The orange sliver on the left edge of a schedule block whose reservation has Early Check In. Drawn also on a stay clipped at the left edge of the visible range (as the card's own rounded edge). The late check-out marker is the same on the right edge and only appears at a real departure edge (D-084) |
| Unassigned lane                     | A place on the Schedule grid for reservations that have no room yet. Not designed or built (Q-19-8)                                                                                                                                                                                                         |
| Checked in / checked out / canceled | Reservation states; canceled and checked-out reservations are read-only in the Hub                                                                                                                                                                                                                          |
| Unassigned                          | A reservation room with no room assigned yet ("UNASSIGNED"); cannot be checked in (the details panel disables Check In); migrated reservations are all unassigned. The New Reservation panel can create one (Location, Room Type and Room all "Unassigned"); the grid has no lane for it yet (Q-19-8)       |
| Closure / room closure              | A gray block that takes a room out of inventory (e.g. "Reserved: Fixed Loss", maintenance); shown on the schedule, a notification trigger (Created, Updated, Removed)                                                                                                                                       |
| Room block                          | A named group of rooms held for an event (e.g. "Member-Guest Tournament"), shown in Quick Stats with nights and counts; the Room Blocks menu item has no design. Also a notification trigger category. Distinct from a schedule block (the rectangle on the grid)                                           |
| Linked room                         | Rooms tied together (e.g. room 500 linked to 510); booking one removes the other from availability; a linked room block on the schedule shows a link icon and the linked room number                                                                                                                        |
| Hold                                | A temporary reservation of inventory while a booking is completed, with a countdown from "Reservation Hold" minutes (per audience). Today only a UI timer in the New Reservation panel (employee audience); no server hold exists                                                                           |
| Early Check In / Late Check Out     | Per-reservation flags (when the system setting is on). Late Check Out keeps the reservation checked in past the standard checkout until the Late Checkout Time, then auto checks out                                                                                                                        |
| Standard check in / checkout time   | System settings (e.g. 4:00 PM, 12:00 PM)                                                                                                                                                                                                                                                                    |
| Room type                           | A category of room with capacity, bed types, features, add-ons, photos and rates; can be "locked" on a reservation so it cannot change room type                                                                                                                                                            |
| Rate category                       | A named rate plan (Comp, Member, Non-Member, Owner Rate; the mock also invents Reciprocal Club, Guest of Member, Event Package). Managed inside Guest Rooms (D-016)                                                                                                                                         |
| Alternative Base Rate               | A base rate that applies for N or more nights (two can be enabled)                                                                                                                                                                                                                                          |
| Adjusted rate                       | A rate changed on a night or charge line via Adjust Rate; the notification snippet "Single Night Rate" shows it instead of the standard rate                                                                                                                                                                |
| Add-on (item)                       | An extra item or service attached to a reservation (e.g. rollaway), with a SKU price; may track nightly quantity ("Track Nightly Countdown"); "Combo" add-on is **Unknown** (Q-73-1)                                                                                                                        |
| Rollaway                            | The example add-on used to explain nightly quantity limits                                                                                                                                                                                                                                                  |
| Keycard                             | A room key encoded at an encoder; "Manage Keycards (N)" lists active keys                                                                                                                                                                                                                                   |
| Encoder / Encoder Key               | The device that writes keycards; an Encoder Key identifies it; retrieved from Visionline (the lock system named in ticket 7.6)                                                                                                                                                                              |
| Registration Card                   | A printable PDF for check in with selectable items and signature areas                                                                                                                                                                                                                                      |
| Print Folio                         | Opens the folio PDF in a new tab                                                                                                                                                                                                                                                                            |

## People

| Term                                | Meaning                                                                                                                                                                                                                                                              |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Reserver                            | The person who makes the booking. On the guest column a Reserver once set and saved cannot go back to Lead Occupant                                                                                                                                                  |
| Lead Occupant                       | The main guest staying; cannot be changed after the reservation is created (it can be switched to Reserver and back to Occupant). In the New Reservation panel it is optional, shows TBD by default and appears when the Reserver option is selected (D-065, Q-19-6) |
| Named Occupant                      | Any additional guest with a name; unnamed ones are TBD                                                                                                                                                                                                               |
| TBD                                 | A guest not yet named; allowed for additional guests online, and a valid saved Booking Guest or Lead Occupant in the New Reservation panel (D-080)                                                                                                                   |
| Booking Guest                       | The guest field of the New Reservation panel: a member autocomplete that shows TBD until someone is chosen, with an Occupant / Reserver choice and a "+" that opens the Add guest dialog (D-064)                                                                     |
| Member                              | A club member with a member number, member rates and a badge treatment                                                                                                                                                                                               |
| Non-member (guest)                  | A booker without a member account; non-member rates; person-search icon                                                                                                                                                                                              |
| Owner / Room Owner                  | A member who owns a room (set per room when the Owner system setting is on); owner treatment is the hand/key icon                                                                                                                                                    |
| Treatment                           | The icon and color styling for guest, member and owner names                                                                                                                                                                                                         |
| Employee / Staff                    | Users of the admin UI; hold audience `employee`; employee roles Admin, Management, Staff                                                                                                                                                                             |
| Administrator / Admin               | May open all Admin Setup pages; sees private notes                                                                                                                                                                                                                   |
| Attendee / Occupant (notifications) | Recipient types: Reserver, Lead Occupant, Named Occupant, grouped by Members and Non-Members                                                                                                                                                                         |

## Money and operations

| Term                                   | Meaning                                                                                                                                                                                                                      |
| -------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Folio                                  | The statement of charges and payments for a reservation. Chips: Folio Open, POS, Not Checked In                                                                                                                              |
| Posted / unposted                      | A posted charge is final on the folio; an unposted charge (e.g. a room rate before its post date) waits for night audit                                                                                                      |
| Settled                                | A charge covered by a payment; shows reference numbers                                                                                                                                                                       |
| Balance Summary                        | Folio balance with a color: grey, yellow, green, red per rules in ticket 4.1                                                                                                                                                 |
| Night audit                            | The end-of-day process that posts room charges (and extra charges and payments) to CMA; the wizard picks a post date, lists pending room charges and posts the selected ones. A manual or automatic mode is a system setting |
| Post date                              | The business date a charge belongs to                                                                                                                                                                                        |
| Batch                                  | A group of posts from one night audit run; reversible in History                                                                                                                                                             |
| CMA                                    | The external accounting/management system that receives night-audit posts and where reversals must also be made. Full name **Unknown**                                                                                       |
| MPOS / Mobile POS                      | The mobile point-of-sale system that creates charges and takes card-present payments; "folio visibility" hours control when a folio shows there                                                                              |
| Unassigned charge                      | An MPOS charge that is on no folio; listed on Unassigned Charges and counted in the dashboard badge; can be transferred or deleted                                                                                           |
| Quick split / Quick Settle             | Split the full folio balance across guests and payment methods; settle the whole balance                                                                                                                                     |
| Split item (parent / child)            | A charge split into parts that settle separately; children cannot be transferred or split again                                                                                                                              |
| Item transfer                          | Moving charges to another open folio or to Unassigned                                                                                                                                                                        |
| Surcharge / Service Fee                | Added when settling to a card present via MPOS (surcharge) or to a card on file in Guest Rooms (service fee)                                                                                                                 |
| SKU                                    | A catalog item code that prices charges, add-ons and room types; "Ask for Price" SKUs allow an entered price                                                                                                                 |
| Penny auth                             | A $0.01 authorization of a new card (System Settings: Enable Credit Card Authorization); when it is triggered is open (Q-32-1)                                                                                               |
| Payment on file / Deposit / Prepayment | Payment models at booking; initially all clubs use payment on file ($0 charged at booking)                                                                                                                                   |
| Paycloud                               | Payment/account system for members (payment methods are managed there). Exact scope **Unknown**                                                                                                                              |
| Core / Axis                            | Axis is the main club site and member system; Core is the non-member account system. Exact products **Unknown**                                                                                                              |
| ADR                                    | Average daily rate; the definition is open (Q-65-1)                                                                                                                                                                          |
| Weighted average rate                  | Total revenue divided by total nights (D-005)                                                                                                                                                                                |
| Occupancy percent                      | booked / (booked + available) in Quick Stats (provisional, D-043)                                                                                                                                                            |
| Revenue (reports)                      | Room charges and add-ons, excluding taxes and service charges (D-004)                                                                                                                                                        |

## UI and technical

| Term                          | Meaning                                                                                                                                                         |
| ----------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Hub (Reservation Hub)         | The reservation screen `/reservations/:id` (not built)                                                                                                          |
| Details panel                 | The drawer on the Schedule (right by default, one setting) for a reservation or a new one; its New Reservation variant has a New Room Closure tab (placeholder) |
| Split CTA                     | A button with a primary action and a menu of secondary actions                                                                                                  |
| Mock / demo mode / scenario   | The in-memory API; a hosted demo build; `normal`, `loading`, `empty`, `error`                                                                                   |
| Grant                         | The permission payload from `GET /permissions/me`                                                                                                               |
| Sentinel (`'all'`)            | The value of `permissions` that means unrestricted                                                                                                              |
| `requestId` / Idempotency-Key | Client id for a mutation so a retry does not apply twice                                                                                                        |
| `version` / stale             | Opaque revision used to refuse a change made from out-of-date data (409 `stale`)                                                                                |
| Unknown outcome               | A request that may or may not have been applied (status 0, 408, 5xx, unusable 2xx)                                                                              |
| Light shape guards            | Checks of the fields the UI needs, not full validation                                                                                                          |
| Slot                          | A `ReactNode` region of the dashboard layout filled by other tickets                                                                                            |
| Manager / specialist agents   | The Claude Code agents that run tickets (`docs/MANAGER.md`)                                                                                                     |
