# Open questions

One consolidated list. It merges the owner's `open-questions.md` (planning notes, kept outside the
repo), every "Open questions" section in the ticket bodies, and every "Needs the owner" item in the
merged and open PRs; duplicates are merged under one id (ticket-specific ids look like `Q-<ticket>-<n>`;
`Q-G-n` are global). Back to the [index](README.md).

**Status values:** **open** (no answer; the default in the "Built default" column is what the code
does, or "nothing built" for tickets not started), **open, default built** (an agent chose a default in
a merged PR and asked the owner to confirm), **answered** (with date and answer), **answered,
follow-up pending**. **Decider:** Owner (the project owner), Designer, Backend (the backend team),
Unknown (no decider named in the sources).

The owner's note says that on 2026-10-16 these were answered and written into the tickets as Decisions:
backend, payments, Figma source, average rate, revenue, cancellation window, hold timer, list defaults,
adjust rate scope, room change, PDFs, embedding, responsive, rate categories, migration mapping, owner icon
(see [decisions.md](decisions.md), D-001 to D-018). The same note lists three items **still needed from the
owner**: the Permissions page screenshot (Q-G-1), what a Combo add-on is (Q-73-1), and how Owner Revenue
Share is computed (Q-67-1).
