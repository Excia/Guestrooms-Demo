# Figma deviations and gaps

Where the build differs from the "CE Guest Rooms" Figma file (`WksR3zAy2S8cDsjrVvRklE`) and why, plus the
frames that are missing. Frames named ARCHIVE are superseded and are not sources (D-012). Back to the
[index](README.md). "Choice" = who decided: **owner** (an owner decision), **ticket** (the ticket text won),
**agent** (a default chosen in a PR and awaiting the owner), **forced** (Figma gave nothing or conflicts
with itself).
