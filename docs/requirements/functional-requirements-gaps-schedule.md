# Functional requirements gap analysis: Schedule

Back to the [index](README.md). Scope: the Schedule area of the owner's functional-requirements document
(sections 15 to 20, plus 27.9 and the parts of 27.3.4 and 27.10 that touch the schedule panel) against what
is built, in progress or ticketed. Documentation only: nothing here changes the code, the board or
[open-questions.md](open-questions.md). Analysis date: 2026-10-20, on `main` at `288dd56` (PR #119 merged).

## 1. Purpose, source of truth and how to read the tables

**Source-of-truth order (set by the owner):**

1. **Figma** ([CE Guest Rooms](https://www.figma.com/design/WksR3zAy2S8cDsjrVvRklE/CE-Guest-Rooms)) is first and
   most current. Never deviate from it.
2. **The functional-requirements document** (the "doc", about 2024) is second. Its functionality and rules
   are correct and add detail and candidate tickets. Its old designs and layout ("zones") are outdated:
   take behavior from the doc and layout, structure and labels from Figma. Where they conflict, Figma wins.
   Doc behavior that Figma does not contradict stays.
3. The built code and the ticket bodies follow the two above; where they differ, this file says which side
   to move.

Doc section numbers are written as `15.9.4`. Only short rule fragments are quoted. The doc itself is not in
the repository.

**Columns.** _Doc §_: the numbered requirement (trivial siblings are grouped). _Today_: what the project
does now (built in #18 grid, #19 panels, which are both on `main`; #20 change room is in progress on
branch `feat/20-change-room-during-stay`; #21 schedule blocks and #22 reservation menus are not started).
_Status_:

| Status   | Meaning                                                                               |
| -------- | ------------------------------------------------------------------------------------- |
| Built    | Implemented on `main` and matches the doc (and Figma where Figma speaks)              |
| Partial  | Part of the behavior is built; the gap is named                                       |
| Planned  | Not built, but a ticket covers it (ticket number given)                               |
| Gap      | Not built and no ticket covers it ("not planned")                                     |
| Conflict | The doc, Figma and/or the build disagree in a way that needs a resolution (section 3) |
| Outdated | Figma replaces what the doc describes; the doc text is superseded                     |

_Figma_: a node id in file `WksR3zAy2S8cDsjrVvRklE` (written `15967:188321`) when a frame covers it; "none
found" means none of the frames checked shows it (the Schedule frames 15967:188321, 15963:188278,
2623:9046, 11905:17751, 1326:19431 and their children), not that the file has none. _Recommendation_: keep
doc behavior, follow Figma, or needs owner decision. **Unknown** marks anything that could not be
determined from the sources.
