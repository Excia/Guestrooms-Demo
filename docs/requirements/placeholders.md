# Placeholders and invented values

Every value in the code that was invented, inferred or left as a stand-in, with where it lives, how to
replace it and which ticket owns the real value. "Owner" is the ticket whose delivery (or the project
owner's answer) supplies the real value. Back to the [index](README.md). Update this file whenever sample
data is added or a placeholder is replaced (see the PR checklist).
